# Portfolio site

Static site: HTML and CSS, no build step.

## Deploy on GitHub Pages
1. Create a public repository named `<username>.github.io`.
2. Upload every file in this folder to the repository root.
3. Settings, then Pages, then "Deploy from a branch", `main` and `/ (root)`, then Save.
4. The site goes live at `https://<username>.github.io/` within a few minutes.
